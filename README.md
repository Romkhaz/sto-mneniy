# Сто мнений — русский корпус человеческих мнений о логическом выводе

> МАКЕТ. Так будет выглядеть репозиторий готового корпуса. Числа и примеры ниже — иллюстрация, не собранные данные.
>
> До выпуска здесь только форма, код и инструкции. Посылки, гипотезы и мнения участников публикуются одним выпуском после сбора: раньше их нельзя показывать ни участникам разметки (увидят задуманные метки), ни моделям (тексты должны быть им незнакомы до прогона).

500 пар «посылка — гипотеза» на русском языке. К каждой паре — не одна «правильная» метка, а 20–30 независимых человеческих мнений: *следует*, *противоречит*, *нельзя сказать*. Сохранены все голоса, время ответа и комментарии участников.

Зачем: на таком корпусе можно измерять, насколько независимо рассуждают модели ИИ в роли судей и насколько они согласны с людьми — на текстах, которых модели не видели при обучении.

## Состав

| Файл | Что внутри |
|---|---|
| `data/pairs.jsonl` | 500 пар: посылка, гипотеза, жанр, источник посылки, способ написания гипотезы |
| `data/votes.jsonl` | каждое мнение отдельной строкой: пара, анонимный участник, ответ, время, комментарий |
| `data/aggregate.jsonl` | по паре: счётчики голосов, ответ большинства, энтропия, группа трудности |
| `data/control.jsonl` | контрольные пары с заведомым ответом, использованные для проверки внимательности |
| `models/` | ответы моделей ИИ на те же пары в двух режимах, с рассуждением и без |
| `docs/` | инструкции авторам гипотез и участникам разметки, протокол сбора |
| `analysis/` | блокноты: согласие людей, сколько голосов достаточно, следы автора в гипотезах |
| `DATASHEET.md` | карточка корпуса |

## Как собран

1. Посылки — 170–200 фрагментов из 5–6 жанров с понятным правовым статусом: официальные документы, энциклопедические статьи, классическая проза, деловая переписка, бытовые ситуации.
2. К каждой посылке команда написала три гипотезы. Часть гипотез написана вслепую, без заданной метки.
3. Каждую пару оценили 20–30 участников, не входивших в команду. Отсев только по контрольным парам и признакам невнимательности, не по несогласию с большинством.
4. Все шаги описаны в `docs/protocol.md`; что и как отсеяно — в `DATASHEET.md`.
