# Карточка корпуса «Сто мнений» (макет)

Формат по образцу «Datasheets for Datasets» (Gebru et al., 2021). Пункты, помеченные «…», заполняются по итогам сбора.

## Мотивация
- **Зачем создан.** Для измерения независимости и согласия с людьми моделей ИИ в роли судей на русском языке. Русского корпуса с распределением мнений на пару не существовало (проверено: …, дата …).
- **Кто создал.** Команда студентов ВИШ НИЯУ МИФИ под руководством Р. Хазеева. Финансирование: …

## Состав
- **Единица.** Пара «посылка — гипотеза» и множество мнений о ней.
- **Объём.** … пар, … мнений, … участников.
- **Жанры посылок и их доли.** …
- **Способ написания гипотез.** … % по заданной метке, … % вслепую.
- **Что записано о мнении.** Ответ, время от показа до ответа (мс), комментарий (необязательный), анонимный номер участника, номер сеанса.
- **Что записано об участнике.** Возрастная группа, направление обучения, родной язык. Имён и контактов в корпусе нет.

## Контроль качества
- **Контрольные пары.** … пар с полным согласием на пилоте; порог … % правильных. Отсеяно … участников.
- **Повторы.** … % пар показаны дважды; несогласие с самим собой на бесспорных парах: …
- **Время ответа.** Медиана … с; отсеяно … участников с медианой ниже … с.
- **Принцип.** Несогласие с большинством основанием для отсева не являлось.
